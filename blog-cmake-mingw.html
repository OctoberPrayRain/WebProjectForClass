基于CMakeTools的MinGW C++环境快速配置

准备工作

  1. C/C++编译器（文档此处使用MinGW-w64 + Ninja），安装好并已纳入系统环境变量
  2. VSCODE已安装C/C++插件（C/C++ , C/C++ Extension Pack, CMake, CMake Tools等）

环境简要介绍（可略过）

MinGW-w64

MinGW（Minimalist GNU for Windows） 是一个用于 Windows 平台的开发工具集，它提供了一组 GNU 工具和库，可以用于编译和构建本地的 Windows 应用程序。MinGW 的目标是在 Windows 环境下提供类似于 Unix/Linux 环境下的开发工具，使开发者能够轻松地在 Windows 上编写和编译 C、C++ 等程序。

MinGW的主要组件有：

  • GCC（GNU Compiler Collection）： GCC 是一个开源的编译器套件，支持多种编程语言，包括 C、C++、Fortran 等。在 MinGW 中，GCC 被用来编译和生成 Windows 平台下的可执行文件。
  • Binutils： Binutils 是一组用于处理二进制文件的工具，包括汇编器、链接器、目标文件处理器等。在 MinGW 中，Binutils 用于将编译后的源代码转换为可执行文件。
  • 运行时库（Runtime Libraries）： MinGW 提供了 Windows 下所需的 C 和 C++ 运行时库，这些库是在编译和链接时所需要的，以便在 Windows 环境下运行程序。
  • MSYS（Minimal SYStem）： MSYS 是一个轻量级的 Unix-like 环境，它在 Windows 上提供了一些基本的 Unix命令行工具 ，使开发者能够更方便地使用命令行进行开发和构建。

Ninja

Ninja是一种构建工具，用来调用各种工具（代码生成器、编译器、链接器等）来编译大型项目。与cmake/make等工具不同，Ninja在设计之初就不是给人写的，只是用于作为其它程序生成的目标。 ninja的设计哲学就是避免任何模糊的内容。比如makefile里面可能经常会用dir/*.cpp来表示源文件，但是这需要查询文件系统才能得到具体内容，是一个很慢而且很不确定的操作。Ninja把这些模糊的操作都交给元构建系统（meta-build system，例如cmake），只留下真正需要编译的命令。 因此，本质上我们可以认为Ninja就是一条一条地列出了具体要执行的命令，然后执行即可。 Ninja会分析这一系列命令之间的依赖关系，并根据这个依赖关系实现两个重要特点：

  • 并行编译： 没有依赖的命令可以并行执行。ninja默认使用的并行数为CPU数量，一般不用手动设置并行数，除非想限制ninja使用的CPU数量（例如有其他任务在运行，只让ninja用一半CPU）。
  • 增量编译： 根据文件的时间戳进行分析，如果某个文件的时间戳发生了改变，则依赖于这个文件的命令以及其他依赖于这个命令的命令都会被重新执行，以此达到增量编译的效果（比如修改了一个文件之后重新编译）。

总的来说，使用Ninja的作用是因为在 Windows 上，MinGW-w64 的默认生成器（如 make）可能效率较低，而 Ninja 能显著减少编译时间（尤其是增量构建），属于优化项而不是必选项。

配置过程

新建项目文件夹

首先创建一个项目文件夹，用于存放未来可能使用到的项目并对这些项目进行管理。

设立项目结构

在项目文件夹下设立好一个项目结构，确保包含CMakeLists.txt文件，build目录作为构建目录应当会跟随CMakeLists.txt文件的存在而自动跟随创建。随后创建src文件夹来存储C++源代码。

编写CMakeLists.txt

cmake_minimum_required(VERSION 3.10)    # 声明 CMake 最低版本要求（避免兼容性问题）
project(CProject)   # 定义项目名称（会初始化相关变量，如 PROJECT_NAME）

# 设置 C 标准（如 C11）
set(CMAKE_C_STANDARD 11)
set(CMAKE_C_STANDARD_REQUIRED ON)   # 强制要求编译器支持 C11（否则报错）

# 添加可执行文件
add_executable(main src/main.cpp)   # 将 src/main.cpp 编译为可执行文件 main.exe

创建新C++文件并在 VSCode 中选择 Kit（MinGW-w64 GCC）

在src文件夹内新建一个 main.cpp文件并写入最简单的C++代码：

#include <iostream>
using namespace std;

int main(){
    cout<<"HelloWorld!"<<endl;
    return 0;
}

此刻按F5运行后，检索控制台会弹出Kit选择项，选择C++(GDB/LLDB)后，再选择g++编译器，选择好后会自动生成main.exe与tasks.json。

创建调试配置

转到"RUN AND DEBUG"界面，找到 "create a launch.json file"，点击后会自动创建DEBUG配置页面，随后对其进行编写：

{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Debug with GDB",
            "type": "cppdbg",
            "request": "launch",
            "program": "${workspaceFolder}/src/exe/${fileBasenameNoExtension}.exe", //使用扩展名，方便项目更名
            "args": [],
            "stopAtEntry": false,
            "cwd": "${workspaceFolder}",
            "environment": [],
            "externalConsole": false,
            "internalConsoleOptions": "neverOpen", //设置为控制台输出
            "MIMode": "gdb",
            "miDebuggerPath": "gdb.exe",
            "setupCommands": [
                {
                    "description": "Enable pretty-printing for gdb",
                    "text": "-enable-pretty-printing",
                    "ignoreFailures": true
                }
            ]
        }
    ]
}

修改配置文件

首先在CMakeLists.txt中指定可执行文件的输出目录为exe/子文件夹：

# 指定可执行文件输出目录
set(CMAKE_RUNTIME_OUTPUT_DIRECTORY ${CMAKE_SOURCE_DIR}/src/exe)

随后修改tasks.json配置文件让可执行文件生成到指定输出路径：

{
    "tasks": [
        {
            "type": "cppbuild",
            "label": "C/C++: g++.exe build active file",
            "command": "C:\\Program Files\\Mingw-w64\\mingw64\\bin\\g++.exe",
            "args": [
                "-fdiagnostics-color=always",
                "-g",
                "${file}",
                "-o",
                "${workspaceFolder}\\src\\exe\\${fileBasenameNoExtension}.exe" //输出exe到src/exe中，便于管理
            ],
            "options": {
                "cwd": "${fileDirname}"
            },
            "problemMatcher": [
                "$gcc"
            ],
            "group": {
                "kind": "build",
                "isDefault": true
            },
            "detail": "Task generated by Debugger."
        }
    ],
    "version": "2.0.0"
}

至此，已经完成了所有的配置过程，已经可以使用MinGW-w64+Ninja的C++环境了。如果需要添加新的cpp文件，则只需要在CMake工具中添加新的可执行文件即可。

Tips：每次请先 Run C/C++ File，编译出exe文件后再进行调试。
