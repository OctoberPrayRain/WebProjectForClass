# WebProjectForClass

一个使用原生 HTML + CSS + JavaScript 制作的柔和二次元个人博客 / 简历作业。

页面以“十月祈雨 / AmeoInoru 的星雨手账”为主题，整合 GitHub、Bilibili 公开入口，以及 RainyOCR、RainyASR、RainyArch、花笺、学习笔记等本地内容改写出的博客文章卡片。

## 运行方式

直接打开 `index.html`，或在本目录启动一个静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。
